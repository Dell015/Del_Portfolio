# Moments photos

Put photos for the Background timeline here.

1. Save the image in this folder, e.g. `ignite-2025.jpg`.
2. In `src/lib/content/timeline.ts`, add it to that moment:

   photos: [{ src: "/moments/ignite-2025.jpg", alt: "What the photo shows", caption: "Optional short line" }]

A second photo is optional; it shows smaller, overlapping the first.
Portrait photos (4:5) fit best. Keep each under about 500 KB (JPG or WebP).
